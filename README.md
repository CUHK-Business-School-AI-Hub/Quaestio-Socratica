## 它不会急着告诉你答案

普通的 AI 教学常常像一本会说话的百科全书：你问，它解释；解释很完整，但理解仍然属于它。

Quaestio Socratica 会换一种方式。

> **导师：** 如果一个漂亮的 AI 回答明天无法稳定复现，我们缺少的真的是一段更长的 prompt 吗？<br>
> **你：** 也许缺少的是一个明确的过程……<br>
> **导师：** 那这个过程中，什么必须由模型判断，什么应该交给规则或人？

一个问题接着一个问题。你提出猜想，撞见反例，修正边界，把零散的概念连成自己的知识结构。导师不会让你无休止猜题：卡住时，它会重述、提示、拆小，最后直接讲明白。

这就是有边界的苏格拉底学习法。

## 主动学习为什么更有趣

因为下一步不是翻页，而是发现。一个反常案例会推翻你刚才的直觉，一个恰到好处的问题会打开新的分支，一个真实任务会突然和抽象概念接上。你不是沿着目录被运送，而是在知识世界里留下自己的路径。

## 你的导师，可以严谨，也可以充满故事

你可以选择三种学习体验：

- **课程导师制**：一位与学科气质相称的原创导师。数学导师追问假设，哲学导师寻找定义与反例，管理导师关注现实中的激励和取舍。
- **沉浸式探索**：进入一个原创世界，与 1–3 位导师共同破解谜题、完成调查或推进一项知识使命，像阅读一部会回应你的《苏菲的世界》。
- **好感度导师模式**：明确确认成年并自愿加入后，与 1–3 位原创成年导师展开乙女游戏式的课程故事。每位导师有 0–3 颗心；checkpoint 后的可跳过选择可以让一位导师加一心，结课时可选群像、友情或符合条件的轻恋爱结局。

课程导师制和沉浸式探索不包含恋爱养成。好感度模式允许轻度、非露骨的调情与恋爱推进，但好感绝不来自答题正确、学习时长、连续签到、服从、付费或强迫披露；拒绝关系选项、暂停或跳过知识点都不会扣好感，也不会让导师降低教学质量。

无论选择哪种体验，你还可以决定导师怎样追问：

- **亲切（默认）**：鼓励、耐心、循循善诱；这是原有的默认教学风格。
- **严格**：把观点、假设、证据和结论拆开检查，不放过含糊概念、隐藏条件或碰巧答对的推理。
- **幽默**：错误答案会收到善意吐槽；概念正确但表达不标准时，导师可以先接梗，再带你落到规范术语。

三种风格只改变反馈语气与追问力度，不改变事实标准。严格不等于羞辱，幽默也不会拿学习者本人开玩笑；卡住时仍会按重述、提示、拆解、直讲的顺序帮助你。

## 三步开始

### 1. 复制一间空教室

复制 [`starter-course`](starter-course/) 文件夹，并给它换成你的课程名字。

### 2. 放入资料，或者只带一个问题

PPT、PDF、讲义、代码、课堂笔记、CSV、网页都可以。资料不完整甚至有错也没关系；没有资料时，也可以直接从一个学习目标开始。

### 3. 在你熟悉的 agent 里开口

用 Codex、Claude Code 或 Cursor 打开整个课程文件夹，然后说：

> 使用这个文件夹里的 Quaestio Socratica skill，帮我建立并开始这门课程。

或者用英文：

> Use the local Quaestio Socratica skill to build and begin this course with me.

不需要编程，也不需要先运行命令。第一次对话会确认：

- 这是教师编课，还是个人自学；
- 你已经知道什么、工作或研究中想解决什么；
- 希望理论、数学、代码和练习分别有多深；
- 使用课程导师制、沉浸式探索，还是需要成年自愿加入的好感度模式；
- 追问风格选择亲切、严格，还是幽默。

AI 会先整理出完整课程路线。只有你明确说“通过”，正式学习才开始。

## 你始终可以说：“我懂了”

非核心内容可以直接跳过。核心内容只需要用自己的话解释一小段；解释有理，就继续前进。

如果你仍然坚持跳过，导师会提示一次风险、诚实记录，然后放行。好的学习系统帮助意愿，不假装制造意愿。

## 学完以后，留下真正属于你的地图

课程结束前，系统会询问是否需要中文、英文或双语版本，然后生成：

- 一份短小的个性化 Cornell 笔记：不是教材摘要，而是你的概念主线、误解、迁移场景与下一步；
- 一张可折叠的 HTML mindmap：课程位于中心，checkpoint 形成主分支，知识节点、先修关系和个人掌握状态一目了然。

## 它可以教什么？

任何能够形成知识结构、问题链和练习反馈的课程：

`数学` · `哲学` · `计算机` · `AI` · `经济学` · `法学` · `语言` · `历史` · `工程` · `管理`

同一套方法可以服务本科生、硕士、博士、EMBA、DBA，也可以服务企业管理者、业务骨干和终身学习者。深度、案例和证据会随 audience 改变，教学内核不变。
