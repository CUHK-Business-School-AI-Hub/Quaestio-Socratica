# Course brief

## Audience

Knowledge workers, managers, analysts, and technical professionals who have used AI chat but have not yet designed a repeatable AI-enabled workflow. No programming is required.

## Prerequisites

- Experience asking an LLM to produce or analyze work.
- One real task that matters enough to improve.
- No assumed knowledge of agent frameworks.

## Transfer context

Turn a useful one-off AI interaction into a workflow that colleagues can repeat, inspect, test, and stop safely.

## Observable learning outcomes

By the end, the learner can:

1. distinguish a prompt, a workflow, and an autonomous agent;
2. define an outcome contract before optimizing a prompt;
3. decompose a task and place deterministic gates or human approvals;
4. choose when data, tools, or memory add justified value;
5. identify prompt injection, excessive permissions, and compounding-error risks;
6. design a small evaluation set around observable outcomes;
7. draft a reliable workflow for one real task.

## Duration and checkpoints

Two fixed checkpoints, approximately 100 focused minutes each:

- `CP01` — From a good answer to a designed workflow.
- `CP02` — Reliability, safety, evaluation, and transfer.

## Scope and exclusions

Included: workflow design, grounding, tools, permissions, failure handling, eval basics, and a capstone workflow canvas.

Excluded: production API implementation, vendor-specific SDK tutorials, model benchmarking, legal compliance certification, and enterprise change management.

## Assumptions requiring approval

- The learner has access to an AI assistant but does not need API access.
- Product interfaces and security guidance can change; current claims retain retrieval dates.
- The capstone is a design artifact, not a production-readiness certification.
