# 开始这门示例课 · Start this demo

## 中文

这是一门已经编译并批准的两 checkpoint 课程：《从提示词到可靠 AI 工作流》。

用 Codex、Claude Code 或 Cursor 打开整个文件夹，然后说：

> 使用本地 Quaestio Socratica skill，开始这门示例课。

agent 会先用 2–3 轮对话了解你的工作、经验和目标，再请你选择课程导师制或沉浸式模式，以及亲切（默认）、严格或幽默的追问风格。

## English

This is an approved two-checkpoint course: *From Prompts to Reliable AI Workflows*.

Open the whole folder in Codex, Claude Code, or Cursor, then say:

> Use the local Quaestio Socratica skill and begin this demo course with me.

The agent will first spend two or three dialogue rounds learning about your work, experience, and goals, then ask you to choose course-mentor or immersive mode and a friendly (default), strict, or humorous questioning style.

No Python or command-line setup is required.
